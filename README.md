# React E-commerce Shopping Cart

A modern e-commerce shopping experience built with React.js. This project demonstrates product browsing, shopping cart management, product details, and order review functionality.

## Features

- Product listing and browsing
- Product details view
- Add products to shopping cart
- Remove items from cart
- Shopping cart state persistence using LocalStorage
- Order review page
- Organized React component structure
- CSS-based user interface and animations

## Technologies Used

- React.js
- JavaScript (ES6+)
- React Router
- HTML5
- CSS3
- LocalStorage
- Git & GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/markket287/older-project.git
```

Go to the project directory:

```bash
cd older-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Open your browser at:

```text
http://localhost:3000
```

## Project Purpose

This project was developed to practice and demonstrate frontend e-commerce development, React component architecture, client-side routing, and shopping cart functionality.

## Current Scope

This is a frontend demonstration project. Product data is provided through local sample data. It does not currently include a production backend, database, or live payment integration.
